# Security

Report vulnerabilities privately through GitHub's security advisory feature for this repository.

Never include a Parcel API key, OAuth token, Cloudflare secret, tracking history, email address, or postcode in a public issue. Revoke an exposed Parcel API key through [Parcel Web Access](https://web.parcelapp.net/) before reporting the incident.

Supported releases are the latest npm release and the current `main` branch.
